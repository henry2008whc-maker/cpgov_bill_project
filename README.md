# H.R. 2026 — Carbon Pollution Reduction and Clean Air Act

Classroom bill-project website for Hancheng Wang, Government Period 2, Fall 2026.

The site contains:

- the policy case and supporting evidence;
- the full proposed bill;
- a double-spaced letter to a representative;
- an MLA-style bibliography with six authoritative sources; and
- additional links for bill research.

Open `index.html` to view the site locally. The repository is designed for GitHub Pages.
